# tokmax — retired

Retired on 2026-09-20. The public leaderboard, profile pages, sign-in, and
publishing service are discontinued. This repository preserves the source and
history; maintenance and releases have ended.

All published npm versions are deprecated. If you previously enabled scheduled
uploads, stop them on each machine:

```bash
tokmax daily off
```

Do not use the retired service for publishing or sign-in.
